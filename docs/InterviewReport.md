# Interview Report Collection

## Overview

The **InterviewReport** collection stores the complete AI-generated interview analysis for a user based on their uploaded resume and a job description.

Each document contains:

# Job description 
    --Stores the complete job description provided by the user.

# Resume (optional)
    --Stores the extracted text from the uploaded resume.

# Self introduction (optional)
    --Stores a short self-introduction provided by the user.

# Resume-job match score
    --AI-generated compatibility score between the resume and the job description.

# Technical interview questions
    --Stores AI-generated technical interview questions covering 3 aspects within it-
    # Question - Technical interview question.
    # Intension - Explains what the interviewer wants to evaluate.
    # Answer - Ideal answer approach generated by AI.

# Behavioral interview questions
    --Stores HR and behavioral interview questions.
    # Question - Behavioral interview question.
    # Intension - Explains what the interviewer wants to evaluate.
    # Answer - Ideal answer approach generated by AI.

# Skill gap analysis
    --Stores skills missing from the user's resume compared to the job description. Represents how important the missing skill is. Also show severity with following values that describes possibility of filling that gap.
    # Low 
    # Medium
    # High 

# Personalized preparation plan
    --Stores a personalized day-wise interview preparation roadmap covering these aspects-
    # day Number 
    # Focus (Main topic to study on that day)
    # Tasks List of tasks to complete.

## Collection Structure

InterviewReport
├── jobDescription : String (required)
├── resume : String
├── selfDescription : String
├── matchScore : Number (0-100)
├── technicalQuestions[]
│     ├── question : String
│     ├── intention : String
│     └── answer : String
├── behavioralQuestions[]
│     ├── question : String
│     ├── intention : String
│     └── answer : String
├── skillGaps[]
│     ├── skill : String
│     └── severity : low | medium | high
├── preparationPlan[]
│     ├── day : Number
│     ├── focus : String
│     └── tasks : String[]
├── createdAt
└── updatedAt
